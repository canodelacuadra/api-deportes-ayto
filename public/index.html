Características

Todo lo que necesitas para la gestión deportiva

Espacios

Consulta y administra instalaciones deportivas disponibles en el sistema.

Reservas

Gestiona solicitudes, disponibilidad y confirmaciones de cada reserva.

Usuarios

Controla perfiles, permisos y datos asociados a cada usuario del app.

Autenticación

Acceso seguro mediante JWT para proteger rutas y operaciones sensibles.

Endpoints

Principales rutas de la API

GET /api/espacios

Obtiene la lista de espacios deportivos.

POST /api/auth/login

Inicio de sesión con credenciales del usuario.

GET /api/reservas

Consulta las reservas registradas o por usuario.

GET /api/usuarios

Lista los usuarios activos del sistema.
